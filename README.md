# Bead Counter - Digital Mindfulness Tally

A lightweight, responsive web application and Progressive Web App (PWA) designed for counting prayers, mantras, malas, and tasbih.

## Features
- **Smooth Bead Tallying**: Interactive bead orb with touch tap and swipe-down counting.
- **Customizable Targets**: Presets for 108 (Full Mala), 54 (Half Mala), 27 (Quarter Mala), 99/33 (Tasbih), 1000 (Chant marathon), or custom targets.
- **Audio & Haptic Feedback**: Realistic wood bead tap clicks, completion singing bowl chime, and vibration support.
- **Visual Themes**: Sandalwood Amber, Sacred Jade, Lotus Crimson, and Night Obsidian.
- **Practice Tracking**: Daily streaks, session history, and completed mala rounds saved automatically via `localStorage`.
- **Installable PWA**: Works offline and can be added directly to mobile home screens.

## Deployment on GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/(root)`.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repository-name>/`.
